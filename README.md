Solution for GitHub Basics Assignment 01
Method 1 (Using Loop):A for loop runs from 0 up to 50.In each iteration, the current number is added to a running total variable (sum), giving us the final result step-by-step.
Method 2 (Using Mathematical Formula):To verify the answer quickly, the standard mathematical formula $n(n+1)/2$ is applied directly where $n = 50$.Both methods print their respective outputs so you can compare and verify that the loop results match the formula.
